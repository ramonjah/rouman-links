# Rouman website development rules

- Use inline SVG for every UI icon (play, pause, external link, refresh, chevrons). Do not use emoji or text glyphs as icons. Decorative SVG must have aria-hidden="true"; controls must have accessible names.
- Preserve the original dark button style without the Liquid Glass redesign, with restrained underlighting and platform-specific hover colors. Keep mobile surfaces sufficiently opaque, avoid expensive stacked backdrop blurs on touch devices, and preserve reduced-motion support.
- Keep previews tied to the actual named track and label their real provider. Never substitute another track for missing audio.
- Validate release names, dates, artwork and outgoing links against sources. Do not invent links or popularity ranks.
- Publish only within the authorization in the current conversation. Respect requests for local-only work.
